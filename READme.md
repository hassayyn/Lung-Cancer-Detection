# Lung Cancer Detection using ResNet101

This project uses deep learning (ResNet101) and Machine learning (Random-forest) to detect lung cancer from chest images and symtomp.

## Features
- Pretrained ResNet101 model
- Image preprocessing
- Model prediction and evaluation
- Grad-CAM visualizations

## Folder Structure
lung-cancer-detector/ │ 
	├── src/ → Python code for training and prediction 
	├── models/ → Saved trained models (.h5) 
	├── notebooks/ → Jupyter or Kaggle notebooks 
	├── requirements.txt 	
	└── README.md
